# Literature

Papers cited in `paper/main.tex` and `paper/supplement.tex`.

* `references.bib` -- every citation, for Overleaf / Zotero.
* `PROVENANCE.md` -- **which paper each equation and each of its components came from.**

## Naming

`year - Author - Title.pdf`, first author only, so the folder sorts chronologically.
